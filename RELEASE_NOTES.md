# TypeLess v0.1.0

## Features

- **Push-to-Talk Global Voice Typing** - Hold Right Ctrl anywhere on Windows, speak naturally in Indonesian or English, and release to automatically type into any focused app.
- **Interactive Spider-Verse Pet Overlay** - Animated Miles Morales mascot that reacts dynamically above the taskbar with real-time equalizers and Spider-Sense lightning arcs.
- **System Tray Microphone Selector** - Switch active audio input devices on the fly directly from the native Windows System Tray menu.
- **Zero-Hallucination Cleaner** - Advanced regex-based cleaner that filters repetition loops, subtitle artifacts, and Whisper hallucinations.
- **Multi-Language Support** - Seamlessly switch between Indonesian (`id`), English (`en`), and Auto-Detect.

## Performance & Polish

- **100% Offline & Private AI** - High-accuracy local `whisper.cpp` engine (`small` model) with zero telemetry, zero analytics, and zero cloud dependency.
- **Ultra-Low Memory Footprint** - Lightweight footprint holding steady at ~35MB RAM during idle and seamless spring transitions.
- **Hardware-Grade SIMD Acceleration** - Optimized multithreaded CPU inference with automatic core clamping.
- **Spider-Punk Brand Identity** - Official studio microphone pin badge icon with chromatic glitch glow and custom dark aesthetics.
