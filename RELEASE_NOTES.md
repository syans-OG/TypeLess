# TypeLess v0.1.0

## Features

- **Push-to-Talk Global Voice Typing** - Hold Right Ctrl anywhere on Windows, speak naturally in Indonesian or English, and release to automatically type into any focused application.
- **Interactive Spider-Verse Pet Overlay** - Animated Miles Morales mascot that pops up dynamically above the taskbar with audio-reactive equalizers and Spider-Sense lightning arcs.
- **System Tray Microphone Selector** - Switch active audio input devices on the fly directly from the native Windows System Tray menu.
- **Zero-Hallucination Cleaner** - Advanced regex-based cleaner that automatically strips repetition loops, subtitle artifacts, and Whisper hallucinations.
- **Multi-Language Support** - Seamlessly switch between Indonesian (`id`), English (`en`), and Auto-Detect.
- **100% Offline & Private** - Powered by local `whisper.cpp` (`small` model) with zero telemetry, zero analytics, and zero cloud dependency.

## Installer Types

TypeLess provides two installer options to suit your needs:

- **Full-Offline Installer (~420 MB)** - Fully self-contained package that includes the Whisper AI `small` model and all required binaries. Ready to use immediately after installation with zero internet connection required.
- **Lightweight Web Installer (~3 MB)** - Minimal setup executable. Automatically downloads the Whisper AI model in the background on first launch.
